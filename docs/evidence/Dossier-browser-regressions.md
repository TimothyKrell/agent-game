## Investigated test-driver issue: canonical anchor drift at archive transition

The established archive-expansion case now uses the actual Dossier document reader. It first obtains a long engine-produced live Act II observation, focuses a stable canonical source row, waits for document positioning to settle, checks that the row is in the viewport with nonzero document scroll, and publishes the terminal archive. The archive's dense cursor changes but the opaque source key remains fixed.

With TIM-23 `0fb03f8` applied, the intermediate `reading-3` driver reported **124.359375px → 679.59375px**, a **555.234375px drift** for the same visible source. Trace: `.dossier-e2e/results/reading-3/artifacts/succession-archive-expansi-20c92-ects-delayed-live-snapshots/trace.zip`; screenshot and error context are adjacent.

The trace records source key `ui-id-1822`, initial `/checkpoint?epoch=live&through=340`, then `/history-anchor?epoch=archive&eventKey=ui-id-1822`, followed by archived checkpoints at `1138` and `1074`. The second archived window was an automatic earlier replacement; the failure screenshot shows the anchor near the bottom of the resulting document.

That intermediate driver added `tabIndex` to a nonfocusable article. The final driver focuses the row's **existing production picture button**, retaining a stable source-key locator, immediate positioning, and the same strict geometric assertion. `worker-anchor-4` passes with **124.359375px → 124.8125px** (0.453125px), live cursor **351** → archive cursor **1202**, and only the correct archived window **1138–1266**. The earlier app-regression report was retracted; no production change or tolerance relaxation was used to obtain this result. The failed artifacts remain preserved.

```bash
DOSSIER_RUN=anchor-repro node node_modules/@playwright/test/cli.js test --config .dossier-e2e/playwright.config.ts e2e/succession.spec.ts --grep 'archive expansion'
```

The full-suite version also attaches `canonical-anchor.json` with both cursor IDs, source key, epochs, document/scroll geometry and exact checkpoint/history URLs. Delayed live-packet rejection and bounded-reader assertions execute before the geometric assertion so their results remain exercised even when the anchor regression is present.
